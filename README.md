# RepTrack v10

Мобільний фітнес-трекер для GitHub Pages.

## Що виправлено у v10
- очищено проєкт від patch/dev файлів;
- стабілізовано iPhone Liquid Glass навігацію без drag-gesture та лагів;
- прибрано виділення тексту під час навігації та сортування;
- drag/drop обмежено робочою зоною та додано блокування виділення під час перетягування;
- swipe-редагування/видалення запису зроблено з контрольованим reveal без перекриття дизайну;
- Heatmap тепер завжди показує останні 13 тижнів до сьогодні, а не від вибраної дати;
- майбутні дні в Heatmap неактивні;
- локальні іконки зберігаються в `icons/`;
- PWA та офлайн-режим збережені;
- сповіщень та OneSignal немає.

## Запуск
Відкрий `index.html` через GitHub Pages або інший HTTPS-хостинг.
